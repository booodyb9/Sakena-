# سكينة — Sakena

تطبيق ويب عربي للقرآن والتلاوات والتفاسير والأحاديث والأذكار ومواقيت الصلاة، بواجهة تدعم الهاتف والكمبيوتر.

## التشغيل

يتطلب Node.js 22.12 أو أحدث.

```sh
npm ci
npm run dev
```

## التحقق والبناء

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

ناتج البناء في `dist/` ويمكن استضافته كموقع ثابت. يستخدم Vite مسارات نسبية لدعم الاستضافة داخل مجلد فرعي.

## متابعة الحفظ

- افتح سورة ثم اختر «الحفظ آية بآية»، أو ابدأ من بطاقة متابعة الحفظ في الرئيسية.
- يتحدث موضع التوقف تلقائيًا عند اختيار آية أو الانتقال إلى السابقة أو التالية.
- «أتممت حفظ الآية» يسجّل إتمامها وينتقل إلى التالية. التنقل وحده لا يسجّل الحفظ.
- يمكن إخفاء الآية للمراجعة الذاتية أو إلغاء تأكيد حفظها.
- «متابعة الحفظ» في الرئيسية يعود إلى السورة والآية المسجّلتين، مع تقدّم مستقل لكل سورة.
- تأكيد الحفظ ذاتي؛ لا يوجد تعرف صوتي أو تقييم آلي للتسميع.

يُحفظ التقدم والمفضلة محليًا في المتصفح على الجهاز. لا توجد مزامنة بين الأجهزة، ومسح بيانات الموقع يزيل هذه البيانات. عند فشل التخزين تظهر رسالة توضح أن التقدم قد لا يبقى بعد الإغلاق.

## التلاوات والمصادر

- التلاوات وقائمة القراء من MP3Quran، وتظهر فقط السور المتاحة للتسجيل المختار.
- يمكن تبديل السورة من داخل المشغّل مع الاحتفاظ بالقارئ والتسجيل.
- نص القرآن والتفسير الميسّر والجلالين من AlQuran Cloud.
- شروح الأحاديث ملخصات بالمعنى مع روابط المصادر، وليست فتاوى.
- مواقيت الصلاة محسوبة بمكتبة Adhan وفق المدينة وطريقة الحساب المختارة.

تحتاج التلاوات والبيانات غير المخزنة مسبقًا إلى الإنترنت. نص الفاتحة مضمّن، والنصوص المفتوحة تخزّن محليًا حيث يسمح المتصفح.

## أندرويد والخلفية

التطبيق PWA قابل للتثبيت من متصفح أندرويد، وليس APK أصليًا. يبقى عنصر الصوت مثبتًا أثناء التنقل وتتوفر أزرار Media Session حيث يدعمها المتصفح. استمرار الصوت عند قفل الشاشة يعتمد على نظام الجهاز وإعدادات البطارية والمتصفح. تنبيهات الصلاة الحالية تتطلب بقاء التطبيق نشطًا.

## الاختبارات

`npm test` يتحقق من استعادة بيانات الحفظ وعزل تقدم السور ومعالجة البيانات التالفة وحدود الآيات. وصف اختبارات قبول الواجهة والمشغّل والتفسير موجود في `tests/tests.json`.
